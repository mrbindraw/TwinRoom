# TwinRoom
This is a simple project to start my journey into UE Digital Twin.  
The mock server sends random data about the room's status: temperature and occupancy.  
On the project map, the cube changes color and displays the room's status as text above it.  

## Dependencies:
- Unreal Engine 5.7
- Python 3+
- [Mosquitto, MQTT-broker](https://mosquitto.org/)

> [!IMPORTANT]
> `Plugins/MQTT` is a git submodule that points to a fork of Epic's
> UnrealEngine repository (my fork MQTT plugin with TLS/mqtts support added).
> GitHub returns `repository not found` for it unless your GitHub account is linked
> to an Epic Games account. This is a requirement of the Unreal Engine EULA.

## Testing MQTT-broker:
1. Switch to the `TwinRoom/MockServer` directory and run in terminal:
```
sh make_certs.sh
```
Remark: If MinGW, POSIX-to-Windows path conversion, add `MSYS_NO_PATHCONV=1` sh make_certs.sh

2. Create `.env` file from `.env.example`

3. Open new terminal and run:
```
make_users.sh
```

4. Open new terminal and run:
```
mosquitto -c mosquitto.conf -v
```

5. Open new terminal and run:
```
python room_publisher.py
```

6. (Optional) Open new terminal and run:
```
python room_subscriber.py
```

7. Launch the UE project  
**TLS setup:** put the broker CA certificate at `Content/Certificates/ca.crt`
   (generated by `MockServer/make_certs.sh`, see below). The MQTT URL (scheme
   `MQTTS`, host, port `8883`, username/password) and TLS verification options are
   in Project Settings → Plugins → MQTT. For packaged builds add `Certificates` to
   *Project Settings → Packaging → Additional Non-Asset Directories to Copy*.
